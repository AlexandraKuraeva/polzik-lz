# 1.01 — подготовка к сдаче

## Сделать до отправки
- Передать Саше Кураевой ветку `plan/1.01-email-i-heshi` (пуш — сам) и дамп для стенда, если у неё его нет.
- Порядок миграции её облачной базы (подробно — DEPLOY.md, раздел про облако):
  1. Table Editor → `users` → Export to CSV. Хеширование необратимо, CSV с открытыми паролями хранить как секрет.
  2. Сначала деплой кода на Vercel; до SQL вход работает по открытым паролям и сам хеширует их.
  3. Сразу потом SQL Editor → весь `supabase/db/polziks-schema.sql` → Run (повтор безвреден). Не тянуть:
     сотрудник с email не в нижнем регистре не войдёт, пока схема не прогнана.
  4. Ошибка «несколько сотрудников с одним email: …» → найти строки по `lower(trim(email))`, проверить
     операции лишней, перенести операции и баланс или сменить ей email, удалить лишнюю, запустить схему снова.
  5. Проверка: `select count(*) from users where password !~ '^\$2';` → `0`.
  - Сброс забытого пароля: `update users set password = extensions.crypt('новый', extensions.gen_salt('bf', 10)) where email = '…';`
